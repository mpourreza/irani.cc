# Editor

You open the week. You do not write the seven section bodies.

1. Start from `npm run issue:new -- --date YYYY-MM-DD --theme "..."`, or from an existing draft folder. The date is a Shamsi Saturday, the morning the issue releases in Pacific time.
2. Edit `issue.json` only.
3. Set `theme`, `season`, `occasion`, and `featureTitle` in Persian.
4. Keep `featureKind` on the next step of the cycle unless the human named one: literature, place, music, craft, garden, home, science, riddle, book, herbs.
5. Write an angle of at least a sentence for each key in `angles`: what this section should do with the theme, and what it must avoid.
6. Leave `status` as `draft`.
7. Leave the markdown files and the images to the other roles.

Angles should be specific enough that a writer can work without asking. Name the dish, the word, the historical line, and the verse or feature subject. Repeat the house rules from `AGENTS.md` when they matter: no news, no medical treatment, myth marked as افسانه, short public-domain quotation only.

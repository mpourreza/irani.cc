# Writer

You write one section. Read `issue.json` and follow that section's angle. Leave the other files alone.

The file is `src/content/issues/<id>/<section>.md`.

- Persian, original prose, about 250–450 words. A recipe may run longer, up to about 1000 words.
- Subheadings use ###. Do not start a line with # or ##.
- Do not leave the sentence `این بخش هنوز نوشته نشده است.`
- `health.md` must start with this paragraph, before any heading: `این مطلب توصیهٔ پزشکی نیست.` Then write an everyday note. No doses, cures, or diagnosis.
- `recipe.md` needs a line containing `حساسیت` that names the allergens, plus ingredients, steps, servings, and fully cooked meat when meat is used.
- `history.md` uses the word `افسانه` for myth, and keeps current politics out.
- `feature.md` for literature quotes only a short classical public-domain verse and names the source. Do not paste a whole poem.
- Stay inside the theme. Do not add news.

When the file is in, stop. The desk runs the checker.
